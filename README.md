## 📖 معرفی کتاب

کتاب **Domain-Driven Design: Tackling Complexity in the Heart of Software** یکی از تأثیرگذارترین منابع در طراحی نرم‌افزارهای پیچیده است. این کتاب به جای تمرکز روی فریم‌ورک‌ها یا تکنولوژی‌های سطحی، مستقیم می‌رود سراغ قلب مسئله یعنی «مدل‌سازی دامنه». با مفاهیمی مثل **Bounded Context**، **Aggregate** و **Ubiquitous Language** یاد می‌گیرید چگونه پیچیدگی سیستم‌های واقعی را کنترل کنید و نرم‌افزاری بسازید که با منطق کسب‌وکار هم‌راستا باشد، نه صرفاً مجموعه‌ای از کدهای قابل اجرا.

این کتاب بیشتر از اینکه درباره کدنویسی باشد، درباره شیوه فکر کردن مثل یک مهندس سیستم است.
